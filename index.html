Methodology — Act 1 card effectiveness

How to read the table: N is how many times the card was picked up by floor 9. With is the Act 1 clear rate (reached Act 2) among runs that had the card by floor 9; Without is the same clear rate for runs that didn't. Diff is With minus Without. Rows with a very low N can swing wildly.

The separate Global winrate (all 3 acts) column is a different, unrestricted stat: the full-run win rate among any run that had the card at any point, on any floor of any act.

Main columns pool every ascension level. The Δ (A9/A10 only) column re-runs the same floor-9 comparison restricted to ascension 9-10 runs only. Each card is only scored using runs played after its most recent balance patch (see Last changed patch).

Methodology — Act 1 Smith value

If you already have a card, is it worth upgrading (Smithing) it the first time you get the chance at a campfire, rather than healing or doing something else? Runs are grouped by roughly where in Act 1 that campfire happened, and only compared against other runs that reached that same point — so a run that simply got further doesn't get an unfair advantage in the comparison. Only a run's first upgrade opportunity for a card counts.

Methodology — Act 1 boss rare card

How to read the table: n is how many runs kept that card after the Act 1 boss fight. Winrate is the full-run (3 acts) win rate for those runs. Diff vs baseline is that winrate minus the baseline winrate for this character's cohort. (skipped) covers runs that beat the boss but kept none of the 3 rares offered.

Main columns pool every ascension level. The Δ (A9/A10 only) column re-runs the same comparison restricted to ascension 9-10 runs only. Each card is only scored using runs played after its most recent balance patch.

Methodology — Act 3 boss card effectiveness

Restricted to runs that won the game. Effectiveness is measured as the average HP lost (damage_taken) in the Act 3 boss fight, comparing runs that owned the card going into that fight against runs that didn't — not a win rate, since every run in the cohort already won.

Main columns pool every ascension level. The Δ (A9/A10 only) column re-runs the same comparison restricted to ascension 9-10 runs only. Each card is only scored using runs played after its most recent balance patch.

Methodology — Colorless cards, Act 1 effectiveness

Same floor-9 landmark methodology as Act 1 card effectiveness above, restricted to Colorless cards and pooled across all five characters. Pooling isn't a simple merge: With/Without/Diff is computed per character first, then combined using a stratified average weighted by each character's smaller with/without group size, so one class's baseline clear rate can't skew the result.

Methodology — Act 1 event effectiveness

Data quirk: not every "?" floor is a narrative event — a "?" map icon can resolve straight into an ordinary monster or elite fight instead of a choice. Those are excluded; only genuine narrative events are scored.

Main columns pool every ascension level. The Δ (A9/A10 only) column re-runs the same floor-9 comparison restricted to ascension 9-10 runs only. Unlike the card and relic reports, there's no per-event patch-change data to filter on, so every run in the cohort is used regardless of patch.
