Winrate by Act 3 elder relic - all ascensions

Act 3 opens with a random elder encounter (Nonupeipe, Tanx, Vakuu, or Darv) that grants a relic. Some of these elders can be fought and can kill the player — runs that died there are excluded from this cohort entirely (they never received a relic to compare), not bucketed as a result. n = runs that received that relic and survived the encounter, restricted to runs on a patch at or after that relic's last balance change (see Last changed patch column). Winrate = full-run (3 acts) win rate for those runs. Diff vs baseline = that winrate minus the baseline for the current character filter. Δ (A9/A10 only) re-runs the same comparison restricted to ascension 9-10 — dash = no A9/A10 data, blank = below the min-sample filter. Rows marked * have a sample < 100. A few relics (Archaic Tooth, Touch Of Orobas, Dusty Tome) have a different in-game effect per character, so they're always broken into one row per class here, never pooled — see the methodology for why.

Full methodology and caveats: see the elder relic methodology on the homepage.
