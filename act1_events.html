All characters combined — Act 1 event effectiveness (all ascensions)

N = times run into by floor 9. With / Without = Act 1 clear rate (reached Act 2) for runs that ran into the event by then vs runs that didn't; Act 1 clear diff = With minus Without. Δ (A9/A10 only) re-runs the same Act 1 clear comparison restricted to ascension 9-10 — dash = no A9/A10 data, blank = below the min-sample filter. Winrate diff is a separate metric on a separate population (of runs that ran into the event at any point in Act 1, not just by the landmark floor): how much more or less often they won the whole game than the "Global winrate (baseline)" KPI above — not the same "with vs. without this event" comparison as the Act 1 columns, so the two can point in different directions for the same event (an event can correlate with clearing Act 1 more often while correlating with winning the run less often, or vice versa). Rows marked * have a small sample (n < 100). This measures which event you ran into, not which choice you made inside it.

Full methodology and caveats: see the Act 1 event effectiveness methodology on the homepage. For the handful of events where the branch itself can be reconstructed from the data, see Event choices.
