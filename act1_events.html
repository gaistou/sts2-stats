N = times run into by floor 9. With / Without = Act 1 clear rate (reached Act 2) for runs that ran into the event by then vs runs that didn't; Diff = With minus Without. Δ (A9/A10 only) re-runs the same comparison restricted to ascension 9-10 — dash = no A9/A10 data, blank = below the min-sample filter. Global winrate (all 3 acts) is a separate, unrestricted stat: of runs that ran into the event at any point in Act 1, how many won the whole game. Rows marked * have a small sample (n < 100). This measures which event you ran into, not which choice you made inside it — the site doesn't record that.
