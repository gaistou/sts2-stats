Ironclad — Act 1 card upgrade value (all ascensions)

Cohort = Ironclad runs (all ascensions). For each card, at every Act 1 campfire where a run still owned an unupgraded copy, we record whether it chose to Smith that card right there or did something else, then compare the subsequent Act 2 clear rate between the two groups — floor-matched (in groups of 5 floors), since both sides already reached that same campfire floor range.

Correlational, not causal: choosing what to Smith is the player's decision, possibly confounded with player skill or deck state. Only each run's first Smith opportunity per card counts, so a run isn't counted twice for the same card. Starting-deck cards (Strike, Defend, ...) are under-tracked since ownership is only known from reward pickups. Rows marked * have a small sample (n < 40 on the smaller side): the gap may just be noise.
