Defect — Act 1 card upgrade value (all ascensions)

Cohort = Defect runs (all ascensions). For each card, at every Act 1 campfire where a run still owned an unupgraded copy, we record whether it chose to Smith that card right there or did something else, then compare the subsequent Act 2 clear rate between the two groups — floor-matched (in groups of 5 floors), since both sides already reached that same campfire floor range.

Correlational, not causal: choosing what to Smith is the player's decision, possibly confounded with player skill or deck state. Only each run's first Smith opportunity per card counts, so a run isn't counted twice for the same card. Starting-deck cards (Strike, Defend, ...) are under-tracked since ownership is only known from reward pickups. Rows marked * have a small sample (n < 40 on the smaller side): the gap may just be noise. The Δ (A9/A10 only) column re-runs the same method restricted to ascension 9-10 runs only, as a sanity check on whether the main columns (pooled across all ascensions, for volume) still hold at high ascension; it respects the same min-sample filter as the main columns, applied to the A9/A10-only sample specifically — a dash means no A9/A10 data existed at all, an empty cell means some existed but not enough to clear the current min-sample threshold.
